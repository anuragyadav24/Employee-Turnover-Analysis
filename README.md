# Employee Turnover Analysis

This project uses Machine Learning techniques to analyze employee data and predict employee attrition. The goal is to identify factors that contribute to workforce turnover and help organizations improve employee retention strategies.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Employee attrition prediction
- Data visualization
- Machine Learning model training and evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Objective
To build a predictive model that helps organizations understand and reduce employee turnover.
